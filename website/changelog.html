开发进度

这里记录已经完成的能力和仍在准备的发布工作。源码公开测试版不是已经签名、公证的正式安装包。

本页目录 现在 0.3.0 0.2.0 0.1.0 下一步

现在 · 0.3 Source Beta

完整 Python 与 Swift 源码已经合并并通过本地构建验证；公开安装包仍未完成 Developer ID 签名与 Apple 公证。

已经完成

  • 一个“收好桌面”按钮，一次处理安全的桌面顶层项目。
  • 文件按 st_mtime、文件夹按可读树中最新修改时间进入月度 Timeline。
  • 同名不覆盖、文件夹不拆散、整理日历和最近未撤销批次的安全撤销。
  • 可主动开启的截图智能、确定性安全改名和改名撤销。
  • 主窗口、文件操作 helper 与菜单栏 Agent 组成的统一本地应用包。
  • 原生 macOS 窗口、完整开源仓库材料和自动化安全测试。
  • 源码已在 GitHub 公开仓库提供。

仍在准备

  • Developer ID 签名与 Apple 公证。
  • 另一台 Mac 的全新安装验证。
  • 将 froganize.com 指向 GitHub Pages 并开启 HTTPS。

0.3.0

2026-08-12 · 统一本地原型
  • 把 Swift 截图理解能力整合为 Froganize Screenshot Intelligence。
  • 通过版本化 JSON 合同把改名、历史与撤销交给 Python 安全 helper。
  • 截图上传默认关闭，只有明确开启后才使用用户选择的 Provider。
  • 新增主窗口截图状态页和包含三个组件的统一本地应用包。

0.2.0

2026-07-29 · 本地开发预览
  • 新增本地桌面评估面板、显式选择和二次确认。
  • 文件夹按最新后代修改时间评估，但移动时始终保持完整。
  • 新增计划快照与变更检测，防止评估后文件变化造成误移动。
  • 新增 Finder 打开、批次历史、最近批次撤销和完整边界校验。

0.1.0

2026-07-19 · 初始 MVP 基线
  • 建立 Python 包与 dropnest 命令行入口。
  • 完成安全工作区初始化、Inbox 预览与月度整理。
  • 完成冲突安全移动、JSONL 历史、状态与撤销。

下一步

先公开可审阅、可测试的源码与官网，再根据真实反馈决定是否投入 Developer ID 签名、Apple 公证和二进制分发。未公证的本地构建不会冒充正式安装包。
