开发进度

这里记录已经完成的能力和仍在准备的发布工作。Developer Preview 不是已经上线的正式版本。

本页目录 现在 0.3.0 0.2.0 0.1.0 下一步

现在 · 0.3 Unified Prototype

本机功能与界面已经可运行；公开安装包尚未完成签名、公证和另一台 Mac 的安装验证。

已经完成

  • 桌面最外层评估，以及最近使用、建议收起、无法安全判断三种结果。
  • 默认不勾选、确认后移动、整文件夹处理和月度 Timeline。
  • 同名不覆盖、操作历史和最近一次整理撤销。
  • 可主动开启的截图智能、确定性安全改名和改名撤销。
  • 主窗口、文件操作 helper 与菜单栏 Agent 组成的统一本地应用包。
  • 原生 macOS 窗口、兼容网页界面和自动化安全测试。

仍在准备

  • Developer ID 签名与 Apple 公证。
  • 另一台 Mac 的全新安装验证。
  • 真实且稳定的官网、GitHub 与下载地址。

0.3.0

2026-08-12 · 统一本地原型
  • 把 Swift 截图理解能力整合为 Froganize Screenshot Intelligence。
  • 通过版本化 JSON 合同把改名、历史与撤销交给 Python 安全 helper。
  • 截图上传默认关闭，只有明确开启后才使用用户选择的 Provider。
  • 新增主窗口截图状态页和包含三个组件的统一本地应用包。

0.2.0

2026-07-29 · 本地开发预览
  • 新增本地桌面评估面板、显式选择和二次确认。
  • 文件夹按最新后代修改时间评估，但移动时始终保持完整。
  • 新增计划快照与变更检测，防止评估后文件变化造成误移动。
  • 新增 Finder 打开、批次历史、最近批次撤销和完整边界校验。

0.1.0

2026-07-19 · 初始 MVP 基线
  • 建立 Python 包与 dropnest 命令行入口。
  • 完成安全工作区初始化、Inbox 预览与月度整理。
  • 完成冲突安全移动、JSONL 历史、状态与撤销。

下一步

优先完成公开分发所需的签名、公证与干净机器验收，再确定域名和公开仓库地址。不会为了让按钮更早可点而跳过 macOS 安全验证。
