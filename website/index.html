macOS Desktop Organizer

给桌面一点整理魔法。

Real local interface

打开以后，
一眼就会用。

主界面只留一个“收好桌面”动作，侧栏用来回看整理日历和管理可选的截图智能。 没有账号，普通桌面整理也不需要 API Key 或网络。

  • 一键收好不用在 Finder 里来回拖拽
  • 整理日历按日期回看批次和去向
  • 截图智能独立、默认关闭的可选功能

Optional Screenshot Intelligence

让截图变成
一眼找得到的名字。

The important boundary

AI 只负责理解，
不直接操作文件。

AI 只返回标题、摘要、类别、置信度和敏感标记。本地安全层再次确认 文件没有被修改，清理不安全字符、处理重名，并以不覆盖方式完成改名。

会发送什么
只有明确开启后，待处理的匹配截图才会发送到你配置的 AI Provider。
什么留在本机
API Key 保存在 Keychain；活动历史不记录截图图片或 API Key。
什么会被跳过
符号链接、不支持的图片、低置信度结果、分析后发生变化的文件和任何无法安全处理的项目。
基础桌面整理不需要 AI。 截图智能目前是 Source Beta 中的可选实验能力，需要你自己提供兼容 OpenAI Chat Completions 格式的 HTTPS 接口。 查看完整隐私边界 →

Local First, by design

整理留在本机，
动作由你发起。

Froganize 少知道一点，也少替你决定一点。 这是它值得信任的方式，不是藏在设置里的选项。

普通整理完全本地
只读取名称、类型和修改时间等必要元数据，不读取或上传普通文件内容。
截图智能由你开启
打开面板和保存设置不会联系 Provider；只有你主动测试连接，或明确同意并开启处理后，才会发起对应请求。仅后者会上传匹配的系统截图。
不自动移动，也不自动删除
打开和刷新都只做只读规划，只有你点击“收好桌面”才会移动安全项目。
不覆盖，而且可以撤销
重名时安全改名，整理日历保留历史，并为最近未撤销批次保留退路。

How the magic began

蛙仔也不是一开始就会整理。

它只是慢慢明白：整理不是让东西消失， 而是给每一件暂时不用的东西，留一个找得回来的去处。

桌面开始堆满

蛙仔试过把文件堆高，也试过假装看不见。 可每一份都像还有用，桌面越挤，它反而越不敢动。

捡到文件夹魔法杖

有一天，它捡到一根文件夹形状的魔法杖。 杖没有让文件凭空消失，只让“留下”和“收好”第一次变得清楚。

学会一次收好

蛙仔学会先查看安全边界和最后修改时间。 主人点一下魔法杖，它就把安全的顶层项目一次收好，不安全的继续留在原处。

让每件东西都有去处

收好的项目进入按年月排列的 Timeline，仍然找得到，也可以在整理日历中回看。 桌面不必空空如也，只需要重新留给此刻正在发生的事。

From story to product

故事里的魔法，在产品里是一次安全的点击。

走进真实界面，蛙仔会换成更克制、更清晰的矢量形象。 打开、收好、回顾和撤销，每种姿态都对应一个真实动作。
