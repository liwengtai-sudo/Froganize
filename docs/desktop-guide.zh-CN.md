# Froganize 桌面整理使用手册

> 当前为源码公测候选，不提供正式签名、公证安装包。重要资料应保持正常备份。

## 你只需要记住两件事

```text
Desktop：现在放在桌面上的项目
Timeline：按最后修改年月收好的项目
```

不需要先把文件放入 Inbox，也不需要逐项拖到 Finder 文件夹。

## 第一步：打开 Froganize

从源码安装后，在项目根目录执行：

```bash
source .venv/bin/activate
python -m dropnest.macos_app
```

应用会打开独立的 macOS 窗口，不需要浏览器、网址或端口。打开时只会评估
Desktop 第一层，**不会自动移动文件**。

macOS 第一次可能请求 Desktop 文件夹权限。Froganize 需要这项权限才能查看和
移动桌面项目；不允许时，应用应报告无法读取，而不是绕过系统权限。

## 第二步：看一眼评估结果

界面会显示当前可收好的数量和留在原位的安全跳过项。

可以收好的项目包括：

- Desktop 第一层的普通文件；
- Desktop 第一层的完整文件夹。

文件夹始终作为一个整体移动。Froganize 不会把内部内容拆开，也不会把文件夹
中的项目单独列出来。

默认留在原位并报告原因的项目包括：

- Froganize 应用和已知旧启动器；
- 隐藏项目；
- 临时文件或未完成下载；
- 符号链接；
- 云端占位、无法读取、不支持的类型和其他无法安全判断的项目。

## 第三步：点击“收好桌面”

点击一次，就授权 Froganize 执行当前显示的准确计划。不需要勾选，也不会再弹出
第二次确认。

普通文件按照 `st_mtime`（最后修改时间）归档；文件夹使用可读目录树中最新的
修改时间，但仍整体移动：

```text
Desktop/report.pdf
→ Timeline/2026/2026-07/report.pdf
```

这不是创建时间，也不是点击按钮时的当前时间。一次点击中的项目可能分别进入
不同月份，但在历史中仍属于同一个 batch，可以一起撤销。

同名目标不会被覆盖。Froganize 会使用 `report (1).pdf`、`Project (1)` 等安全
新名称。执行前还会重新检查来源是否改变、目标是否被占用。

## 第四步：查看结果

完成页会显示移动、跳过和失败数量。可以打开 Timeline 查看按年、月排列的结果。
Timeline 中的文件以后再次修改，不会自动换月份；Froganize 只在你下一次明确
点击“收好桌面”时处理仍位于 Desktop 第一层的项目。

## 第五步：查看记录或撤销

点击侧栏“整理日历”：

1. 有整理记录的日期会显示蛙仔标记；
2. 点击日期查看批次、原始名称、Timeline 去向和恢复状态；
3. 较早批次只读保留；
4. 最近一次尚未撤销的成功整理可以执行撤销；
5. 原位置已有同名项目或 Timeline 目标已消失时，该项目不会被覆盖，并会明确报告。

撤销失败一个项目不会破坏其他已经安全恢复的项目。

## 可选功能：截图智能

截图智能是次要实验功能，默认关闭。普通桌面整理不会调用 AI、不会上传内容，
也不需要 API Key。

如使用截图智能，需要自行填写兼容的 HTTPS AI 接口、模型和 API Key，并接受
截图上传说明。API Key 由 macOS Keychain 保存。Swift 后台组件源码位于
`swift/ScreenshotIntelligence/`，可以随主仓库一起构建和测试。

## 安全提醒

- 先保持 Time Machine 或其他正常备份。
- 打开应用和刷新评估都不会移动文件。
- 只有点击“收好桌面”才会执行当前批次。
- 不跟随符号链接，不覆盖已有项目，不永久删除文件。
- 测试开发功能时只使用临时合成目录，不要使用真实 Desktop。
