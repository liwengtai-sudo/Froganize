# Froganize brand

Froganize is the public product name and mascot for the project. The existing
Python package and command remain `dropnest` for compatibility.

## Naming

- **Froganize** — product, interface, mascot, and public-facing brand.
- **DropNest** — compatibility name for the Python package, CLI, workspace
  metadata, and safety core.
- **Froganize, powered by DropNest** — preferred wording when both names need
  to appear together.

Please write the product name as `Froganize`, with a capital F. Avoid
`FrogAnize`, `Froganise`, or all-caps variants in body copy.

## Core message

> Review first. Move only what you choose.

Froganize is intentionally not described as an automatic cleaner. It assesses,
recommends, waits for confirmation, and keeps the latest archive batch
reversible.

## Brand asset use

You may use unmodified Froganize screenshots, logos, and mascot artwork to:

- discuss, review, or teach the project;
- link to the official repository;
- report on development;
- show an integration or community contribution.

Please include a visible reference to Froganize or the project repository when
practical.

Please ask the maintainers before using the mascot or logo:

- as the identity of another product or organization;
- on merchandise offered for sale;
- in a way that implies official endorsement;
- in substantially modified form as a competing brand.

This brand-use guidance does not restrict the MIT-licensed source code. It is
not a claim of registered trademark status.

## Asset provenance

The Froganize mascot and campaign scenes were created specifically for this
project with AI-assisted image generation, then selected, directed, edited, and
integrated by the project maintainers. Product screenshots and diagrams are
generated from synthetic demo data and the real local interface.

See [the brand guide](docs/brand-guide.md) for colors, layouts, and the complete
asset index.
