# Application icon assets

- `froganize-app-icon.png` — 1024 × 1024 source icon with transparency;
- `Froganize.icns` — macOS launcher icon consumed by
  `scripts/install_macos_launcher.sh`.

The character identity and color rules are documented in
[`docs/brand-guide.md`](../docs/brand-guide.md). Superseded local icon
experiments are intentionally ignored and are not part of the public project.
